# 个人 IP 风格规范

以下六种风格与中文 HTML 样式库一一对应。参考图片位于 `../assets/style-library/assets/references/`。

## IP-01 简笔涂鸦头像

适合制作极简、亲切的头像和轻量表情包。

- **参考图片：** `style-06/ref-01.png` 至 `style-06/ref-04.png`。
- **线条：** 粗黑、略带颗粒和抖动感，线头圆润，允许轻微断笔。
- **配色：** 以白色为主，保留粉色腮红，可加入一种低饱和点缀色。
- **比例：** 圆形大头、小脖子、小肩膀，可画到半身。
- **五官：** 点状或短线眼睛，小鼻子、小嘴巴，信息极简。
- **气质：** 直接、随和、柔软、亲切，适合社交头像和聊天反应图。
- **避免：** 复杂刻画、写实人体、复杂背景和光滑精致的矢量效果。

提示词基底：极简手绘涂鸦个人 IP 头像，粗而柔软的黑色线条，圆形大头，极简五官，粉色腮红，大面积白色，只保留一种低饱和点缀色，居中构图，亲切可辨，线条带轻微颗粒和手绘不规则感。

## IP-02 清透扁平肖像

适合制作高度简化、现代且容易辨认的博主头像。

- **参考图片：** 默认使用 `style-02/ref-01.jpg` 至 `ref-03.jpg`；`ref-04.jpg` 仅用于用户明确选择的成熟分支。
- **线条：** 几乎无描边，以边缘明确的大色块直接塑造轮廓。
- **配色：** 清晰平涂，每个区域最多两级平面明暗，不使用摄影高光和渐变。
- **比例：** 头像、肩像或半身为主，头部明显放大。
- **五官：** 夸张黑色椭圆眼睛，小色块鼻子，弧线嘴巴，不画真实牙齿和嘴唇。
- **头发：** 简化为 5–8 块流畅、连贯的大形状，不画发丝和尖锐碎片。
- **气质：** 明亮、整洁、亲切，适合知识、生活方式和职场类博主。
- **避免：** 半写实动漫脸、低多边形切面、写实皮肤、细密发丝、三维渲染和空气感光影。

提示词基底：高度几何化的清透扁平个人 IP 肖像，几乎无描边，以大色块概括人物；头部明显放大，黑色椭圆大眼，小色块鼻子和弧线嘴巴；头发由 5–8 块流畅大形状构成，每个区域最多两级平面明暗。几何化不是低多边形，不使用摄影高光、渐变、写实皮肤、细密发丝或常规精致动漫脸。完整模板见 `generation-prompts.md`。

## IP-03 粉蜡笔撞色肖像

适合制作造型高度夸张、色彩醒目、情绪活泼的油画棒大头肖像。

- **参考图片：** `style-01/ref-01.jpg` 至 `style-01/ref-04.jpg`。
- **线条：** 由厚重、不透明的粉蜡笔和油画棒直接塑形，边缘保留干刷、断裂与涂抹痕迹。
- **配色：** 使用粉、钴蓝、明黄、黑和肤色组成高饱和撞色色块。
- **比例：** 头部约占画面三分之二，双手可在脸旁靠近镜头，发型轮廓突出。
- **五官：** 两个醒目的圆形色块眼睛，小色点鼻子和简单实心嘴形，不使用常规动漫眼睛。
- **气质：** 有表现力、活泼、俏皮，适合信息流中的高辨识度头像。
- **避免：** 先画光滑数字动漫人物再叠颗粒滤镜、常规动漫脸、写实五官、满版彩色背景和细密发丝。

提示词基底：完全非写实的粉蜡笔撞色个人 IP 肖像，头部约占画面三分之二，眼睛为醒目的圆形色块，鼻嘴高度图形化；脸、头发、衣服和双手都由厚重不透明的油画棒色块直接构成。白底，少量粉蓝黄手绘符号点缀。不是精致动漫插画添加蜡笔滤镜。完整模板见 `generation-prompts.md`。

## IP-04 彩铅换装小人

适合用完整穿搭、配饰和动作来塑造身份的全身人物。

- **参考图片：** `style-05/ref-01.png` 至 `style-05/ref-04.png`。
- **线条：** 柔和灰色或彩铅轮廓，带纸张纤维和毛茸颗粒感。
- **配色：** 浅淡糖果色，低到中等对比，皮肤带柔和粉色。
- **比例：** 约 2.5–3.5 头身，身体紧凑，完整展示服装和鞋子。
- **五官：** 小眼睛、小嘴巴、圆脸颊，表情含蓄。
- **气质：** 怀旧、俏皮，带纸娃娃和收藏贴纸的感觉。
- **避免：** 写实修长比例、坚硬纯黑矢量轮廓和拥挤场景。

提示词基底：柔和彩铅全身个人 IP 小人，约三头身比例，完整展示服装、鞋子和配饰，低饱和糖果色，纸张与铅笔颗粒，小五官、圆脸颊，像可收藏的换装纸娃娃，独立呈现在干净背景上。

## IP-05 治愈手帐小剧场

适合制作日常叙事、生活场景，以及带植物、宠物或小道具的连续内容。

- **参考图片：** `style-04/ref-01.png` 至 `style-04/ref-04.png`。
- **线条：** 松弛的细黑线或彩色手绘线，搭配简单平涂。
- **配色：** 克制的自然色或主题色，通常保留 2–4 种主要颜色。
- **比例：** 简单小人物置于微型场景中，人物肖像细节可以适度减少。
- **五官：** 点状极简五官，搭配轻微腮红。
- **气质：** 治愈、安静、童趣，像手帐中的小故事。
- **构图：** 人物搭配一个有意义的场景元素、植物、宠物、物件或季节符号。
- **避免：** 密集电影场景、强烈三维纵深和光滑商业吉祥物效果。

提示词基底：治愈系手帐个人 IP 插画，小人物处于简单日常微型场景，松弛细线，克制自然配色，极简五官和淡淡腮红，搭配一个有意义的道具、植物或陪伴物，大面积留白，安静而有故事感。

## IP-06 粗线撞色漫画

适合制作线条强烈、对比鲜明、第一眼记忆点突出的漫画肖像。

- **参考图片：** `style-03/ref-01.jpg` 至 `style-03/ref-04.jpg`。
- **线条：** 很粗的黑色轮廓，形状高度概括，线条有统一力量感。
- **配色：** 高饱和两色或三色体系，黑色通常占较大面积。
- **比例：** 大头或上半身肖像，头发形成明确的块面轮廓。
- **五官：** 大而图形化的眼睛或简化漫画五官，表情直接。
- **气质：** 自信、古灵精怪、有冲击力，带海报感。
- **避免：** 细腻彩铅、浅淡水彩、写实光影和混乱的线条粗细。

提示词基底：粗线撞色漫画个人 IP 肖像，极粗黑色轮廓，头发形成强烈深色块面，高饱和两到三色配色，简化的大眼睛和直接有趣的表情，平面海报式构图，在信息流中具有高辨识度。

## 六种风格的共同要求

- 保留用户真实的发型、发色、眼镜状态、脸型和标志性外观。
- 参考图只用于定义视觉语言，不复制参考人物的身份、服装、文字、水印和作者签名。
- 用户确认原型后，所有表情和动作都必须遵守同一份人物锚点。
- 除非所选风格依赖小场景，否则优先使用纯色或透明背景，方便制作贴纸和后续排版。
