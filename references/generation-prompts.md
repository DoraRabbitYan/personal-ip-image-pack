# 个人 IP 生图提示词

生成图片时先读取本文件，再读取 `style-presets.md` 中所选风格。不要把风格名称直接当作完整提示词。

## 组装顺序

按以下顺序写提示词：

1. 标注每张输入图的职责。
2. 写人物身份锚点，并说明照片中哪些写实信息不要保留。
3. 写所选风格的造型、五官、线条、色块、明暗和材质。
4. 写服装、动作、背景和画幅。
5. 写禁止项，阻止写实化、风格漂移和参考人物复制。

## 通用输入规则

- 使用 1–2 张身份图和 2–3 张内部一致的风格图，总数不超过图像工具上限。
- 身份图只提供脸型、年龄感、发型、发色、分缝、眼镜状态和标志性穿搭。
- 风格图只提供头身比例、五官简化、线条、色块、阴影、材质和背景语言。
- 不保留真人照片的皮肤纹理、真实鼻唇结构、牙齿细节、单根发丝、景深和摄影光影。
- 不复制风格参考人物的发色、宠物、服装、道具、文字、签名、水印或身份。
- 原型阶段优先单人、简单纯色背景、无文字、无无关道具。
- 用户提供或确认过一张满意的生成结果时，把它作为最高优先级的风格锚点；其他风格图只补充细节，不能把造型重新拉向别的分支。

## IP-01 简笔涂鸦头像

```text
图1至图N只提供身份锚点：[填写脸型、发型、发色、分缝、眼镜和标志性服装]。不要保留真人皮肤纹理、真实鼻唇结构、牙齿、发丝和摄影光影。
其余参考图决定全部绘画语言，不复制参考人物的身份、服装和配饰。

生成极简手绘涂鸦个人IP头像。圆形大头、小脖子、小肩膀；五官压缩为点和短线；粗而柔软的黑色线条，线头圆润，带轻微颗粒、抖动和自然断笔。以白色为主，保留粉色腮红，只加入一种低饱和点缀色。居中构图，大面积留白，缩小后仍清楚可辨。

禁止写实人体、复杂阴影、光滑矢量描边、精致动漫五官、复杂背景、文字、签名和水印。
```

## IP-02 清透扁平肖像

默认使用 `style-02/ref-01.jpg`、`ref-02.jpg`、`ref-03.jpg`。这三张属于年轻、大眼、清透扁平分支。`ref-04.jpg` 的脸型和气质更成熟，除非用户明确选择成熟方向，否则不要混入。

```text
图1、图2只提供身份锚点：[填写脸型、发型、发色、分缝、眼镜状态、服装颜色]。
不要保留真人照片的皮肤纹理、真实鼻唇结构、牙齿细节、单根发丝和摄影光影。
图3至图5决定全部绘画语言；不要复制参考人物的白发、宠物、服装、道具或身份。

生成高度几何化的清透扁平卡通肖像，不是半写实动漫肖像。这里的“几何化”只表示用简洁轮廓和大色块概括结构，不是低多边形切面。
几乎无描边，只用干净、边缘明确的大色块塑造人物。
头部明显放大，保持身份锚点中的脸型；眼睛是夸张的黑色椭圆；鼻子缩成一个小色块；嘴巴只保留简单弧线，不画真实牙齿和嘴唇。
[填写头发]简化成5至8块流畅、连贯的大形状，不画单根发丝、碎发或尖锐多边形发片。
脸部、脖子和头发最多使用两级平面明暗，阴影边缘清晰，不使用渐变。
[填写服装、动作]。清浅蓝绿色纯色背景，1:1构图。

禁止写实皮肤、空气感光影、细密发丝、三维渲染、低多边形切面、常规精致动漫脸、文字、签名和水印。
```

IP-02 自检：

- 看起来应是平面卡通，不是半写实动漫，也不是低多边形人物。
- 头发应由 5–8 块流畅大形状构成，不能变成发丝、三角碎片或塑料体块。
- 眼睛应是夸张黑色椭圆，鼻嘴应高度简化。
- 明暗最多两级；“清透”来自干净配色和留白，不来自摄影高光或渐变。

## IP-03 粉蜡笔撞色肖像

通常直接使用本节的风格规则和原始参考图生成，不要求每次查看旧成图。只有连续生成结果偏向常规动漫脸或数字插画时，才使用 `../assets/style-library/assets/references/style-01/approved-anchor.png` 做一次校准。这个风格的核心不是给数字插画叠加颗粒，而是从人物比例、五官、头发到手势都直接由厚重油画棒色块构成。

```text
图1至图N只用于识别[填写中分、发色、头发长度与卷度、脸型、眼镜状态和服装颜色]。
不要复制真人照片的真实五官比例、皮肤、嘴唇、牙齿、鼻梁、单根发丝、场景和摄影光影。
其余参考图决定人物比例、五官变形、油画棒笔触和撞色色彩；不要复制参考人物的身份、发色、服装、文字或签名。

生成完全非写实的粉蜡笔撞色卡通肖像，不是精致动漫插画添加蜡笔滤镜。
头部占画面约三分之二，脸型圆润夸张；眼睛扩大为两个醒目的圆形色块，由白色眼白、单一高饱和虹膜和黑色圆形瞳孔组成，不画写实高光、睫毛和复杂眼部结构。
鼻子只画一个短小色点，嘴巴缩成一个简单实心图形，耳朵可以适当放大。
[填写头发]保留分缝和蓬松外轮廓，但必须由粗大、厚重、连贯的油画棒色块组成；允许加入少量蓝色、紫色和黄色蜡笔笔触作为撞色，不画真实发丝。
脸、头发、衣服和双手都直接由厚重、不透明的粉蜡笔与油画棒笔触构成，边缘保留干刷、断裂和涂抹痕迹，不能先画光滑数字人物再覆盖颗粒纹理。
使用粉、钴蓝、明黄、黑和肤色组成高饱和色块。[填写动作；默认双手在脸旁向前挥手]。纯白背景，只有少量手绘十字或圆点点缀，1:1构图。

禁止常规动漫脸、写实眼睛、真实皮肤、真实鼻唇、牙齿、摄影光影、细密发丝、平滑数字渐变、细腻数字绘画、半写实肖像、黄色或蓝色满版背景、文字、签名和水印。
```

IP-03 自检：

- 头部是否约占画面三分之二，而不是普通半身肖像比例。
- 眼睛是否是圆形色块，而不是带反光和睫毛的常规动漫眼睛。
- 所有区域是否由厚重油画棒直接构成，而不是光滑底图叠颗粒滤镜。
- 背景是否保持白色，仅用少量粉、蓝、黄手绘符号点缀。
- 黑色长卷发是否保留身份轮廓，同时出现克制的蓝、紫、黄色粗笔触。

### IP-03 全身延展模板

当用户确认头像或半身原型后，再用本模板扩展全身图。锁定的是约 4.5–5 头身的轻盈比例，不锁定测试人物的具体下装和鞋子。

下半身穿搭按以下优先级决定：

1. 用户明确指定的下装、袜子和鞋子。
2. 用户照片中清楚可见且具有标志性的穿搭。
3. 根据账号定位、人物气质、季节和已确认上衣，补全一套简洁协调的下装与鞋子。

无法判断时，先给出一句简短穿搭建议再生成；不要默认所有人物都穿 A 字裙和靴子。

```text
输入图是已经确认的人物头像或半身原型。把同一个人物自然延展为完整全身形象，不要重新设计脸、发型、上衣、配饰、配色和绘画材质。

严格保持：[填写已确认的脸型、五官简化、发型、发色、眼镜、上衣、配饰、主色和笔触]。

生成完整全身标准原型。人物从头顶到鞋底全部出现在画面内，四周留出充足留白，不能裁切头发、手、下装或鞋子。
采用轻盈、苗条但仍然卡通化的约4.5至5头身比例：头部约占完整身高的四分之一；肩膀偏窄，腰线清楚，躯干自然修长；手臂纤细但保持圆润；双腿较长、纤细、笔直，腿长约占肩部以下高度的一半。不要三头身纸娃娃比例，也不要写实成人或夸张时装模特比例。

完整穿搭：[根据人物特点填写下装]、[填写袜子或腿部处理]、[填写鞋子]。下装与鞋子必须符合用户照片、账号定位、人物气质、季节和已确认上衣，不能机械套用其他人物的穿搭。
[填写全身动作；默认正面自然站立，一只手轻松挥手，另一只手自然垂下]。姿态挺拔、轻盈、自然，不僵硬、不性感化。

人物的身体、服装和鞋子必须使用与已确认原型完全相同的线条、色块、笔触和材质绘制。背景与画幅沿用已确认原型；默认纯色或白色背景、1:1居中构图。

禁止：大头三头身、矮胖体型、粗短腿、宽肩、没有腰线、写实成人身体、过度细长的时装插画比例、性感姿势、半身裁切、擅自更换上衣和配饰、机械套用A字裙或靴子、改变画风、文字、签名和水印。
```

全身比例自检：

- 头部是否约占完整身高的四分之一，而不是接近一半。
- 人物是否约 4.5–5 头身，腰线清楚，整体轻盈但仍是卡通比例。
- 腿是否比三头身小人更长更细，但没有变成写实时装模特。
- 下装和鞋子是否来自当前用户信息，而不是复制测试案例。
- 脸、头发、上衣、配饰和画风是否与已确认原型一致。

## IP-04 彩铅换装小人

```text
身份图只提供人物锚点和穿搭信息；风格图决定全部绘画语言。
生成约三头身的柔和彩铅全身个人IP小人，完整展示服装、袜子、鞋子和配饰。身体紧凑，四肢短，五官小而含蓄，圆脸颊带浅粉腮红。使用低饱和糖果色、柔和灰色彩铅轮廓、纸张纤维和毛茸颗粒，像可收藏的换装纸娃娃。人物独立站在干净背景上。
禁止写实修长比例、坚硬纯黑矢量轮廓、光滑3D渲染、拥挤场景、文字、签名和水印。
```

## IP-05 治愈手帐小剧场

```text
身份图只提供人物锚点；风格图决定人物与场景的全部绘画语言，不复制参考图中的植物、宠物或服装。
生成治愈系手帐个人IP插画。小人物使用极简点状五官、淡淡腮红、松弛细线和简单平涂，身体比例小巧克制。围绕人物只安排一个与主题有关的微型场景元素，例如植物、宠物或日常物件；人物与元素共同形成清楚的小故事。使用2至4种克制的自然色或主题色，大面积留白，画面安静、童趣、像手帐页。
禁止常规Q版大眼、商业吉祥物光泽、复杂电影场景、强烈三维纵深、写实光影、无关道具堆积、文字、签名和水印。
```

## IP-06 粗线撞色漫画

```text
身份图只提供人物锚点；风格图决定全部绘画语言。
生成粗线撞色漫画个人IP肖像。大头或上半身构图，极粗且统一的黑色轮廓，头发形成一整块有冲击力的深色外形；五官是大而图形化的漫画眼睛和直接有趣的表情。使用高饱和两到三色体系与纯色海报背景，可加入一个与用户有关的简洁符号作为记忆点。
禁止细腻彩铅、浅淡水彩、写实光影、复杂渐变、混乱线宽、过多装饰、文字、签名和水印。
```

## 迭代规则

- 保存最近一次被用户认可的完整提示词作为基线。
- 每轮只改一个被点名的变量，并复述保持不变的部分。
- 用户要求回退时，完整恢复旧基线，不混入后续版本的词语。
- 如果输出同时偏离身份和风格，先减少参考图并明确图片职责，不继续堆叠形容词。
- 原型确认后，把原型图作为第一身份参考；扩展表情和动作时只修改表情、姿势、手势和必要道具。
