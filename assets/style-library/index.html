IP-03 · 粉蜡笔撞色肖像

4 张参考共同定义一个方向
IP-03

粉蜡笔撞色
肖像 IP

不是精致动漫，也不是普通扁平插画。它更接近用粉蜡笔、丙烯干刷画出的时尚卡通肖像，人物有一点倔强、有一点好奇。

颗粒干刷夸张大眼高饱和撞色半身肖像
人物比例
大头半身为主，耳朵、眼睛、发型都可以略微夸张。
笔触质感
保留油画棒 / 粉蜡笔的颗粒、涂抹边缘和局部干刷，不做光滑矢量面。
配色逻辑
以一个抢眼发色或服装色为主角，用蓝、粉、绿、黄做少量撞色点亮。
表情延展
适合近景的“惊讶、嫌弃、灵感来了、开心、思考”等脸部情绪，表情要大。

IP-02 · 清透扁平肖像

4 张参考共同定义一个方向
IP-02

清透扁平
肖像 IP

柔和的平面色块、干净边缘和极少阴影，让人物显得安静又有辨识度。适合以发型、眼神和一个陪伴物做记忆点。

平滑色块纯色背景动漫大眼陪伴物
人物比例
以头像或半身正面为主，眼睛偏大，但轮廓和五官保持干净克制。
笔触质感
几乎没有颗粒和手绘纹理，使用平滑块面与少量柔和明暗，画面很清透。
配色逻辑
一个大面积纯色背景加 2-3 个主色；发色和服装可成为整张图的标志。
表情延展
适合“平静、无语、开心、害羞、好奇”等轻情绪，也可用一只宠物或个人物件增强记忆点。

IP-06 · 粗线撞色漫画

4 张参考共同定义一个方向
IP-06

粗线撞色
漫画 IP

粗黑描边、夸张圆眼和高饱和纯色背景带来很强的第一眼记忆点。发型、耳饰、星星或花朵都可以变成用户自己的标志物。

粗黑描边高饱和背景夸张大眼标志小物
人物比例
大头半身、圆眼和小鼻小嘴，头发与眼睛是最强的个人识别点。
线条质感
轮廓用粗黑线，局部保留一点不规则手绘感；服装褶皱和五官只画必要信息。
配色逻辑
背景使用一块饱和纯色，人物以深色头发或鲜艳服装形成大面积对比，点缀控制在两种以内。
表情延展
非常适合做“震惊、开心、无语、委屈、灵感来了”等大情绪，也能围绕头发加入星星、花朵和标志性配件。

IP-05 · 治愈手帐小剧场

4 张用户参考共同定义一个方向
IP-05

治愈手帐
小剧场 IP

像手帐里画出来的个人角色：圆润、留白、带一点随手涂鸦感。人物可以和植物、宠物、花束或日常小物自然组合，画面很有陪伴感。

手帐线条大留白圆脸腮红植物与宠物
人物比例
Q 版大头、小身体，五官极简；发型、帽子或衣服轮廓可以被有趣地夸张。
线条质感
黑色或深色手绘线条带一点不均匀感，局部用短小排线和随手涂鸦增加温度。
配色逻辑
以白底和一种主色为核心，最多再加一到两种柔和辅助色，让画面始终干净。
表情延展
特别适合扩成一套全身动作、场景小剧场和宠物互动；可做“出门、抱猫、喝咖啡、思考、庆祝”等连续内容资产。

IP-04 · 彩铅换装小人

4 张用户参考共同定义一个方向
IP-04

彩铅换装
小人 IP

小小一只、穿搭完整、道具明确。它把“人设”放在服装、鞋子、包包和动作里，画面像一张温柔的彩铅角色贴纸。

彩铅颗粒全身换装糖果低饱和生活道具
人物比例
头大身小的全身 Q 版，脚、帽子、衣摆和配件都可以略微放大，造型很有收藏感。
笔触质感
用细颗粒彩铅或蜡笔上色，轮廓是偏灰的铅笔线，不要使用过于锋利的纯黑硬边。
配色逻辑
以粉、蓝、黄、绿等低饱和糖果色为主，同一人物每次控制在两到三种主色。
动作延展
最适合做换装和生活动作：下雨、上学、旅行、抱书、散步、喝饮料、拿相机；道具能直接承载博主的内容定位。

IP-01 · 简笔涂鸦头像

4 张用户参考共同定义一个方向
IP-01

简笔涂鸦
头像 IP

用不那么规整的粗黑线，画出圆圆的脸和简单五官，再留一小块腮红或彩色装饰。信息很少，但反应和性格很直接。

粗颗粒线大留白粉色腮红轻量点缀
人物比例
以大头、半身甚至头像为主，身体只保留最必要的轮廓，不强调写实比例。
线条质感
黑色线条要有蜡笔或粗马克笔颗粒感，允许微微抖动和断笔，避免过度精致。
配色逻辑
白底为主，只用黑线、肤色、粉色腮红，再加入一个低饱和小色点作为区分。
动作延展
最适合头像、聊天反应和短句贴图：点头、摇头、疑惑、开心、哭哭、比心。复杂全身换装不建议放在这一风格里。
